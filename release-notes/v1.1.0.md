# walq 1.1.0

walq 1.1 adds a second SQLite adapter based on the built-in `node:sqlite` API.

## Highlights

- New `@walq/sqlite` adapter with no external SQLite driver or native npm addon
- Works with Node.js 22.16+, Bun 1.4.2+, and Deno 2.9.7+
- Existing `@walq/better-sqlite3` adapter remains supported with the same public API
- Both adapters use the same database schema and migrations
- Existing databases can be opened with either adapter without conversion
- Shared SQLite implementation moved into `@walq/sqlite-common`
- Added cross-adapter conformance, concurrency, and runtime tests

## Install

Using the built-in SQLite adapter:

```sh
pnpm add @walq/core@1.1.0 @walq/sqlite@1.1.0
```

Using better-sqlite3:

```sh
pnpm add @walq/core@1.1.0 @walq/better-sqlite3@1.1.0
```

`@walq/sqlite-common` is installed automatically by the adapters.

## Switching adapters

Both adapters use schema v12 and the same migrations, so an existing walq database can be reopened with either adapter without format conversion.

Stop workers and back up file-backed databases before upgrading or switching adapters.

See the [`@walq/sqlite` README](../packages/sqlite/README.md) and [`@walq/better-sqlite3` README](../packages/better-sqlite3/README.md) for setup details.
