# Security Policy

## Supported versions

Only the latest published minor version receives security fixes while Walq is in the `0.x` series.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/unsady/walq/security/advisories/new). Do not open a public issue for an undisclosed vulnerability.

Include the affected version, impact, reproduction steps, and any suggested mitigation. You should receive an acknowledgement within seven days.
